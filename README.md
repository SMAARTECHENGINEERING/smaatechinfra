## 🚀 How to Run

### Step 1 — Install dependencies
```bash
npm install
```

### Step 2 — Start development server
```bash
npm run dev
```
Open: **http://localhost:5173**

### Step 3 — Build for production
```bash
npm run build
```
Output goes to `dist/` folder — ready to deploy.
